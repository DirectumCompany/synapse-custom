# Matrix Synapse — Кастомная сборка Docker (v1.155.0)

> **Примечание:** Это неофициальная модифицированная конфигурация сборки Docker для Matrix Synapse, поддерживаемая 
компанией **Directum** (2026) на условиях лицензии **GNU Affero General Public License v3.0 (AGPL-3.0)**.  
> Оригинальный репозиторий проекта: https://github.com/element-hq/synapse

## Внесённые изменения

По сравнению с официальным репозиторием Matrix Synapse были изменены следующие файлы сборки:
* **`Dockerfile.fetch` и `Dockerfile.build`**: процесс сборки разделён на два этапа (предварительная загрузка 
зависимостей и финальная сборка образа).
* **`.dockerignore`**: обновлены правила исключения файлов для корректной работы двухэтапной сборки (локального 
офлайн-кэша).

## Инструкция по сборке

Выполните следующие шаги, чтобы воспроизвести сборку Docker-образа из официального исходного кода Matrix Synapse:

### 1. Скачайте исходный код оригинального Synapse
Скачайте и распакуйте исходный код **Matrix Synapse v1.155.0** со страницы официальных релизов:
* Страница релиза: https://github.com/element-hq/synapse/releases/tag/v1.155.0

### 2. Скопируйте изменённые файлы сборки
Скопируйте файлы из этого репозитория (`Dockerfile.fetch`, `Dockerfile.build` и `.dockerignore`) в корневую директорию 
распакованных исходников Synapse `v1.155.0`, заменив оригинальный файл `.dockerignore`.

### 3. Включите Docker BuildKit
В терминале (находясь в корневой директории исходников Synapse) включите поддержку BuildKit:

**Для Windows (CMD):**
```cmd
set DOCKER_BUILDKIT=1
```

**Для Linux / macOS:**
```bash
export DOCKER_BUILDKIT=1
```

### 4. Загрузите зависимости (Этап 1)
Запустите сборку по первому Dockerfile, чтобы скачать и сохранить зависимости в локальный офлайн-кэш:

```bash
docker build --output type=local,dest=.\docker\offline-cache -f Dockerfile.fetch .
```

### 5. Соберите финальный образ (Этап 2)
Запустите сборку по второму Dockerfile, чтобы собрать итоговый образ Synapse с использованием подготовленного кэша:

```bash
docker build -t synapse:v1.155.0 -f Dockerfile.build .
```
